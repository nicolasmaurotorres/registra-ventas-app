# Registra Ventas

App Android personal (Kotlin) para registrar ventas de papelería creativa, seguir sus envíos y ver estadísticas.

## Agent skills

### Issue tracker

Issues y specs viven como GitHub Issues en nicolasmaurotorres/registra-ventas-app (CLI `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Las 5 etiquetas canónicas por defecto (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` en la raíz. See `docs/agents/domain.md`.
